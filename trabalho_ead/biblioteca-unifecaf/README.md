# Biblioteca Digital UniFECAF

Projeto acadêmico de Design Web desenvolvido com HTML5 e CSS3, a partir do protótipo de baixa fidelidade fornecido no enunciado.

## Estrutura

```text
biblioteca-unifecaf/
├── index.html
├── css/
│   └── style.css
├── assets/
│   └── imagens/
└── README.md
```

## Como executar

Abra o arquivo `index.html` em um navegador ou use uma extensão de servidor local, como Live Server. O projeto não depende de JavaScript ou framework.

## Decisões do projeto

- Paleta baseada no azul institucional, com coral e tons claros para criar hierarquia e acolhimento.
- HTML semântico, navegação por âncoras, foco visível e link para pular ao conteúdo.
- Grid e media queries para reorganizar cards, navegação e unidades em telas menores.
- Tipografia Space Grotesk para títulos e DM Sans para leitura contínua.
